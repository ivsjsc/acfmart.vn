# ACF Mart Android Application

This is the native Android implementation of the ACF Anti-Counterfeit E-commerce Platform.

## Features

- **VNeID Login Simulation**: Secure login entry point (simulated for demo).
- **Role-based Dashboards**: Custom interfaces for Customers, Shop Owners, Moderators, Carriers, and Admins.
- **Product Verification**: Placeholder for QR-based anti-counterfeit verification.
- **Escrow Payment**: Placeholder for secure escrow-based transactions.

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Design System**: Material Design 3
- **Navigation**: State-based navigation mirroring the storefront demo.

## How to Build

1. Open this directory (`apps/android-app`) in Android Studio.
2. Sync Project with Gradle Files.
3. Run the `app` module on an emulator or physical device.

## Project Structure

- `app/src/main/java/com/acfmart/app/MainActivity.kt`: Main entry point containing all screens and navigation logic.
- `app/src/main/res/`: Resources including themes and strings.
